🏈 Friends NFL Pick'em

Four friends. Against-the-spread picks. Weekly bragging rights.

This free static demo saves picks only in this browser. To synchronize four friends across devices, connect a shared database (instructions in README). No automatic Vegas odds are represented as available here.

Submit picks

Picks can be edited before each game's kickoff. The Sunday 1:00 PM ET pool deadline locks any remaining games, and unpicked games get a random selection. Thursday and Saturday games lock at their own kickoff. Earlier picks reveal only when all four players submit, or at the Sunday deadline.

Pool board

Commissioner: spreads

Set spreads manually using your preferred Vegas consensus source. Enter the HOME team's spread (e.g., -3.5 means home favored by 3.5). This version does not scrape or claim to fetch live Vegas odds.

Data & setup

This version is a working single-browser prototype, not a secure multi-user production service. The commissioner may export/import a JSON file to transfer data. For a real four-person pool, use the optional Firebase upgrade described in README.
